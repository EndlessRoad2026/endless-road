# Endless Road

A desert survival driving game made by Louis (with a little help from Claude).

Pick a world (Desert, Snowy Mountains or Jungle), drive as far as you can, and scavenge abandoned houses and wrecked cars for food, fuel, tools and spare parts.

**Play:** https://endlessroad.co.za

## Controls
- Drive: W A S D or the arrow keys, H heater, P pause
- On foot: W A S D walk, Shift run, Space jump
- E: get in or out, pick up, take off or put on car parts
- F eat, G drop what you're holding
- R car radio, N next song, [ ] volume

## How it's built
Plain HTML and JavaScript with [three.js](https://threejs.org) for the 3D graphics. All models, textures and music are generated in code, so there are no external assets. Open `index.html` in a browser to play locally.
